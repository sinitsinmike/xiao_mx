Workflow

    
    
      
  1. Нажми Connect и выбери порт XIAO.
    2. 
      
  2. Нажми Read, чтобы считать текущую конфигурацию.
    3. 
      
  3. Измени CC/Channel и нажми Apply (применит на устройстве без записи).
    4. 
      
  4. Если всё ок — нажми Save, чтобы записать во флеш XIAO. Для бэкапа используй Export JSON или Read → Save file. Для пресетов — Save/Load A/B/C.
